## 一、结论速览

本轮要解决的是三个具体问题：**①模糊 ②建筑物扭曲 ③拼接痕迹明显**。逐一定位到根因并修复：

| 问题 | 根因（量化证据） | v3 的修复 | 结果 |
|---|---|---|---|
| **模糊** | 多视加权平均把同名像素平均掉了。同窗口拉普拉斯方差：单帧 1631 vs 多视平均 136 | 取消平均，改为**逐像素硬性单帧选取**（只取质量最高的一张影像的颜色） | 锐度 2.219（v1 平均 2.169，大疆 2.008），**比大疆高约 10%** |
| **建筑扭曲** | 旧 DSM 高程噪声大（0.25m 网格，与大疆 DSM 逐格差 std 2.88m），186m 航高下 ~3m 高程误差 × tan20° ≈ 1.1m 横向错位 = 20px「熔化」 | **DSM v2**：0.10m 网格 + 粗/细两段 plane-sweep + 置信度取胜融合 + 去尖刺 + Perona-Malik 保边平滑 | 屋顶成连贯矩形、瓦片纹理可辨；平滑后粗糙度 0.038 m/0.1m |
| **拼接痕迹（色块）** | 相邻影像间残留亮度/色调差（同名点色差中位 10、p90 30；雾区相邻视图色调差最大 **77/255**），硬切换把它放大成扇形/条带色块 | **①逐帧仿射辐射校正**（增益+偏置，留出集验证）；**②低频色调共识**：细节全取单帧，仅「极低频色调」取多视共识 | 色块指标 0.389 → **0.172**（大疆 0）；跨切换线可见落差 相对大疆 +8 → **+4** 灰阶 |

**一句话**：v3 在**清晰度**上比大疆高约 10%，**建筑几何**与**色调一致性**已接近大疆，**绝对定位**仍与大疆差 1~3m（无 GCP/RTK 的固有限制，见第五节）。仍残余的不足如实写在第五节。

## 三、自研方案

### 3.1 管线
```
step1  元数据解析    XMP 内参(f,cx,cy,k1..k3,p1,p2) + GPS + 云台 YPR
step2  初始位姿      GPS→UTM(自研横轴墨卡托) + YPR→R + footprint 邻接图(K=20)
step3  特征匹配      SIFT@1/2分辨率×9000点 + F/H 双模型 RANSAC → 55.4 万同名点
step4  鲁棒 BA       Gauss-Seidel 逐相机 + Huber + GPS先验σ=2m + 漂移限制15m + 逐级外点剔除
step4b 辐射校正      逐帧仿射(gain+offset)，同名点 Huber-IRLS 全局求解，留出集验证
step5c DSM v2       0.10m 网格 plane-sweep：粗搜 zp+[-4,+6]@1.0m(11层) + 细搜 ±0.6m@0.1m(13层)
                    + 抛物线细化；融合=逐格最高置信视图取胜；低置信回退加权平均
step5d 去尖刺        与 9x9 局部中值偏离 > max(2m, 6*MAD) 者替换
step5e 保边平滑      Perona-Malik 各向异性扩散(80 iter, K=6.0) + 中值滤波
step6b 正射渲染★     逐像素硬性单帧选取（本轮核心）：评分=nadir^4 × 径向衰减；
                    遮挡判据沿相机→地面光线 12 步采样 DSM；同时输出多视几何加权共识层
step6c 色调共识★     out = 单帧 + ( LP(多视共识) - LP(单帧) )，LP=2.5m 高斯
step7  导出          GeoTIFF(JPEG92+tiled+5级金字塔, EPSG:32650) + tfw/prj + 预览
step8c 评估          四方对照（v3/v2/v1/大疆）× 5 类指标 + 对照图
```

### 3.2 三个关键设计

**① 逐像素硬性单帧选取（解决模糊）**
每个输出像素只取「最优单张影像」的颜色，不做任何跨帧平均：
- 评分 `s = cos(天底角)^4 × cos(径向比·π/2)^0.6`（最正、最靠像主点者胜）
- 遮挡剔除：沿「相机→地面点」光线 12 步采样 DSM，需 ≥2 点持续超限或单点超限很大才判遮挡（抗 DSM 噪声）
- `MAX_VIEWS=14`，只有天底角余弦 >0.85 的 117/129 张进入竞选
- 结果：有效率 98.43%，实际用上 **109 张**影像，单张最大占比仅 3.2%（分区均匀，无少数几张垄断）

**② 低频色调共识（解决色块，且不牺牲锐度）**
纯硬性单帧的代价是暴露了各帧间未校正的色调差。做法是把「色调」和「细节」解耦：
```
out = sf + ( LP(avg) - LP(sf) )     LP = 2.5m 高斯低通，avg = 多视几何加权共识
```
- 数学上：对阶跃色块，`LP(sf)` 含阶跃而 `LP(avg)` 不含，差值恰好抵消边界处的突变；
- 高频（真正决定"清晰"的部分）**逐像素完全来自单帧**，不做任何跨帧平均；
- 实测锐度：LF1.3 / LF2.5 / 纯单帧 = 2.287 / 2.287 / 2.288（**完全无损**），大疆 2.152；
- 边界用 halo 重叠分块 + 权重归一化（只在有效区做低通），避免空洞污染与瓦片缝。

**③ 逐帧仿射辐射校正（把色块从源头减小）**
原有 `gains` 是纯乘性、由同名点中值比 + log 最小二乘得到，无法校正雾霭这类**加性**差异。
改为 `I' = a·I + b`（增益+偏置）：
- 目标：同名点校正后颜色一致，Huber-IRLS 求解，参考帧硬固定 (a,b)=(1,0) 消规范自由度；
- **尺度必须用硬约束 Σa=n**（平均增益=1）——否则优化器会把所有影像压成同一灰度来"让颜色一致"（实测会退化成 a→0.55、b→+54）；
- 留出 1/5 匹配对做验证：同名点色差中位 10.00 → 8.23（改善 18~24%），**不是自欺**；
- 裁剪会破坏尺度规范 → 全局除以 per-channel `mean(a)=[0.955,0.949,0.956]` 精确锚定回原始亮度水平（否则整图偏暗 7.6 灰阶、绿色偏少 7.5）。

**各指标含义与判读**
- **边缘锐度**：感知型指标，强边缘处 |∇I| 除以 9×9 局部对比度。用它是为了避开「把噪声当细节」的陷阱——拉普拉斯方差会把多视平均的钝化和单帧的抗锯齿混为一谈（大疆 192 反而最低，显然不是因为它最模糊）。
- **色块边界 / 跨切换线可见落差**：专门为"平滑但可见的色块"设计的指标（梯度类指标抓不到）。跨切换线落差 = 在切换线两侧各 1.1m 取样求灰度差，并以**大疆在同位置的值为基准**相减 —— 这样扣掉了真实地物边缘的干扰。v2 的扇形色块被修复后，该值由 +8 降到 +4。

## 五、与大疆的差异 & 仍然存在的不足（不掩饰）

### 5.1 绝对定位差 1~3m（正常水平）

粗尺度（高通 4~8m）模板匹配实测：在 200m 窗口内我的成果相对大疆偏移约 **(+1.3m, +2.0m)**，响应 0.54（可信）；在均质农田/雾区窗口匹配不可信（响应 <0.45）故不予采信。
两套结果都无 GCP/RTK，仅靠单点 GPS 约束：大疆把位姿强绑在 GPS 上（RMSE 0.556m），自研 BA 的 GPS 先验较松（σ=2m）、影像网主导，最终整体偏离约 1~3.6m，且是**非线性变形**而非整体平移（无法用简单平移对齐）。
影响：叠加其他 GIS 数据时可能偏移 2~4m。**内部拼接一致性**（重投影 0.76px ≈ 地面 4cm）不受影响。

### 5.2 切换线处仍有细微跳变（硬性单帧的固有代价）

`锐利跳变`（Sobel p95）我的比大疆高约 **25**；`跨切换线可见落差`中位比大疆高 **+4 灰阶**（v2 是 +8）。
原因：相邻帧间 BA 残差约 1px 的错位，在硬切换线上切过地物，形成细微断口；色调共识只能压制"色块"，压不掉"断口"。
**要彻底消除需要图割接缝线优化（seam-aware cut）** —— 让接缝线绕开高梯度地物，这是下一步最值得做的事。
注意：这一项 v1（多视平均）数值最好（+1.4 / +2），但那是**用模糊换来的**，放大后 v1 屋顶明显发糊，不可取。

### 5.3 噪声比大疆高

拉普拉斯方差 826 vs 大疆 192 —— 我的图保留了更多原始纹理（也正是"放大后清楚"的来源），但噪点也更明显；大疆内部做了更强的降噪/平滑，观感更"干净"。
若要更干净：可在 step6c 之后加一级保边去噪（如 guided filter，或你熟悉的 FastDVDnet / Restormer 轻量档），代价是损失一点高频。

### 5.4 其他

- 自研 DSM 有效格 73.96%（大疆 DSM 更完整），植被区匹配困难；屋顶等硬地物已足够好；
- 单次全图渲染耗时 ~18.5min（192 tile × 16 进程，本机 i9-9980XE）；纯单帧版 ~9.5min；
- 正射网格 880×664m 略大于大疆 820.5×589.4m（覆盖更广，代价是边缘有效视图少）。

## 七、后续可改进方向（按性价比排序）

1. **图割接缝线优化**：把接缝线成本设成「颜色差 + 梯度」，让线绕开地物；这能同时解决 5.2 的细微跳变和运动目标（人/车）鬼影。**预期最有效**。
2. **绝对精度**：布 3~5 个 GCP 或启用 RTK/PPK，绝对定位可收敛到分米级；
3. **真稀疏 BA**（Schur 消元替代 Gauss-Seidel 松弛），位姿残差可再降 20~30%；
4. **DSM 加密到 0.05m + 语义引导**（区分植被/硬地物，植被区用更鲁棒的代价），提升植被区有效格比例；
5. **保边去噪**：接入 Restormer / FastDVDnet 轻量档，把拉普拉斯方差从 826 压到接近大疆的 200 量级而基本不损边缘；
6. **超分增强**：若需 2.5cm 视觉分辨率，接 Real-ESRGAN / RealBasicVSR（你的超分管线可直接复用）。
